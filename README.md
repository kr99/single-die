# The Sigil Die

A translucent glass oracle die with glitching arcane glyphs, floating in a ritual chamber.
Built with WebGL2, Three.js, and hand-written GLSL.

## Run it

```bash
npm install
npm run dev
```

Open the printed local URL. For a production build:

```bash
npm run build
npm run preview
```

## What it does

- **Three die shapes** — D6, D8, and D20, switchable from the facet-count picker.
- **Real glass** — `MeshPhysicalMaterial` transmission with IOR, dispersion, attenuation,
  clearcoat, iridescence, and an area-light/PMREM environment for specular highlights.
- **Genuinely rounded** — each polyhedron is generated by projecting a dense icosphere onto a
  smooth-max SDF of its face planes, then deriving normals from that SDF. The result has
  watertight, smooth edges and corners with no bevel seams.
- **Glitching sigils** — every facet carries an additive shader decal that samples a
  procedurally drawn 64-sigil atlas and tears between symbols in RGB-split slices.
- **Refraction you can see** — the chamber wall, rune halo, and reflective floor are opaque,
  so they feed Three.js's transmission buffer and distort behind the die.
- **Poke to cast** — click/tap the die (or press Space) to spring it onto another facet, with
  an impact wobble and a burst of glyph glitch energy.

## Structure

```
src/main.ts        renderer, camera, HUD, interaction, quality fallback
src/die.ts         die construction, materials, animation, poke logic
src/polyhedra.ts   face planes, rounded SDF geometry, decal frames
src/glyphs.ts      procedural sigil atlas and rune drawing
src/glyphMaterial.ts  per-facet glitch shader
src/rimMaterial.ts    Fresnel edge glow shell
src/world.ts       chamber, lights, halo, motes
src/textures.ts    procedural wall, floor, environment, glow textures
src/postfx.ts      bloom + film-grade compositing
```

No runtime assets are downloaded: the sigils, textures, and environment are generated at
startup on a 2D canvas.

Software renderers are detected automatically and switch to a reduced-resolution, lighter-glass
path so the die still moves smoothly. Append `?quality=high` or `?quality=low` to force a path.
